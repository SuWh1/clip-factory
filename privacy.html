Privacy Policy

Clip Factory is a private tool used only by its owner. It does not collect data from anyone else.

Last updated: November 15, 2026

Data it accesses

When the owner signs in with Google, Clip Factory asks for access to their YouTube account to:

  • upload and schedule videos on the owner's channels (YouTube Data API);
  • read basic information about the owner's channels and videos (YouTube Data API);
  • read view and watch-time statistics for the owner's own videos (YouTube Analytics API).

How the data is stored

Sign-in tokens and statistics are stored only on the owner's computer. Clip Factory runs no server of its own. Finished clips, and a weekly summary of the owner's own view counts, are sent only to the owner's private Telegram chat so the owner can review them.

Sharing

Clip Factory does not sell, share or transfer any data to third parties, and does not use it for advertising. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

Clip Factory uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time on the Google security settings page. Deleting Clip Factory's data folder removes everything it stored.
